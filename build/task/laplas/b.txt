Нахождение оригинала по изображению (преобразованию) Лапласа

Дано. Изображение, где | - вертикальное деление
‾‾‾‾‾
2p | p² - 1

Шаг 1. По методу неопределенных коэффициентов
‾‾‾‾‾‾
2p | (p - 1)(p + 1) = A / (p - 1) + B / (p + 1)

A(p + 1) + B(p - 1) = Ap + A + Bp - B = 2p + 0

Получим систему:

{ A + B = 2    { A - B = 0    } => A = 1, B = 1

Шаг 2. Применим обратное преобразование
‾‾‾‾‾‾
2p | (p - 1)(p + 1) = 1 / (p - 1) + 1 / (p - (-1)) = e⁻ⁱ - eⁱ
