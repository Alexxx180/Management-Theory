Найти передаточную, переходную функции и частотные характеристики типового звена

Дано. Уравнение
‾‾‾‾‾
2y'(t) + y(t) = 3u(t)

Шаг 1. Упрощаем выражение с помощью преобразования Лапласа
‾‾‾‾‾‾
Предположим y(0) = 0

y'(t) -> pY(p) - 0    y(t) -> Y(p)    u(t) -> U(p)

W(p) = Y(p) / U(p)    2pY(p) + Y(p) = 3U(p)

Шаг 2. Находим передаточную функцию
‾‾‾‾‾‾
Y(p)(2p + 1) = 3U(p) => W(p) = Y(p) / U(p) = 3 | 2p + 1

Шаг 3. Используя комплексную запись, находим:
‾‾‾‾‾‾
W(iw) = 3 / (4w² + 1²) - i (6w | 4w² + 1²) - Тип звена: Апериодическое

Шаг 4. Находим амплитудно-частотную характеристику (АЧХ):
‾‾‾‾‾‾  _____________________        _______
A(w) = √36w² + 9 / (4w² + 1)² = 3 | √4w² + 1

Шаг 5. Находим фазовую частотную характеристику (ФЧХ):
‾‾‾‾‾‾
φ(w) = -arctg(2w)

Шаг 6. Находим переходную функцию по изображению:
‾‾‾‾‾‾
H(p) = W(p)(1 / p) = 3 | p(2p + 1)

Применяем метод неопределенных коэффициентов

3 | p(2p + 1) = A / p + B | 2p + 1 => A2p + A + Bp = 0p + 3

{ 2A + B = 0    { A + 0 = 3 } => A = 3, B = -6

3 | p(2p + 1) = 3 (1 / p) - 6 (1 | 1 + 2p)

Находим оригинал и получаем переходную функцию

h(t) = 3 - 3e⁻¹ᴵ²ⁿ
