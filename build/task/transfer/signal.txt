Определить выходной сигнал y(t)

Дано. Входной сигнал x(t), передаточная функция W, a, b, w
‾‾‾‾‾
a = 23, b = 2, x(t) = a sin(bt) = 23 sin(2t), W = 1 | p + 1

Из условия Xₘₐₓ = 23, w = 2

Шаг 1. Используя комплексную запись, находим:
‾‾‾‾‾‾
W(iw) = 1 | iw + 1 = 1 / (w² + 1²) - i (w | w² + 1²)

Шаг 2. Получаем f четную R и нечетную Q из левой и правой части уравнения:
‾‾‾‾‾‾
R(w) = 1 | w² + 1²    Q(w) = -w | w² + 1²

Шаг 3. Находим амплитудно-частотную характеристику (АЧХ):
‾‾‾‾‾‾  _____________    ____________________        _______
A(w) = √R(w)² + Q(w)² = √w² + 1² / (w² + 1²)² = 1 | √w² + 1² = 1 / √5 = √0.2

Шаг 4. Находим фазовую частотную характеристику (ФЧХ):
‾‾‾‾‾‾
φ(w) = arctg(Q(w) / R(w)) = arctg(-w / (w² + 1²) | 1 / (w² + 1²)) = -arctg(w) = -arctg(2) ~ -1.1071487

Шаг 5. Определяем выходной сигнал y(t)
‾‾‾‾‾‾
Введем переменную c = sin(2t - (-1.1071487))

y(t) = Yₘₐₓc = XₘₐₓA(w)c = 23√0.2 sin(2t + 1.1071487)
