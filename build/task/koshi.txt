Решение задачи Коши - нахождение начальных условий

Дано. Система уравнений, где n - латинская буква
‾‾‾‾‾
⎧ y'(n) + 2y(n) = 2
⎩ y(0) = 0
⎩
y''(n) + 23²y(n) = 2, где n - латинская буква

Шаг 1. Характеристическое уравнение
‾‾‾‾‾‾
Меняем количество производных y ,', на λ в степени

nλ² - 23²n = 0, прим. y без ' = λ⁰

Раскладываем разность квадратов и выносим n за скобки

n(λ - 23)(λ + 23) = 0, где λ₁ = -23, λ₂ = 23

‾‾‾‾‾‾
