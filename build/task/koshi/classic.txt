Классическое решение задачи Коши

Дано. Система уравнений, где n - латинская буква
‾‾‾‾‾
{ y'(n) + 2y(n) = 2    { y(0) = 0

Шаг 1. Преобразование в общий вид, где | - вертикальное деление
‾‾‾‾‾‾
dy(n) / dn = 2y(n) + 1;    ∫dy(n) / dn | 2y(n) + 1 = ∫dn

Шаг 2. Взятие интеграла, где c - константа
‾‾‾‾‾‾
1 / 2 ln(2y(n) + 1) = n + c;    ln(2y(n) + 1) = 2(n + c);    2y(n) + 1 = e²ⁿ⁺ᶜ

Шаг 3. Общее решение
‾‾‾‾‾‾
2y(n) + 1 = e²ⁿ⁺ᶜ;    y₀(n) = 1 / 2 (e²ⁿ⁺ᶜ - 1)

Шаг 4. Частное решение - находим константу
‾‾‾‾‾‾
1 / 2 (e²ⁿ⁺ᶜ - 1) = 0 => c = 0;    yₕ(n) = 1 / 2 (e²ⁿ - 1)

Таблица интегралов, где | - деление, |n| - модуль, c - константа
‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
0∫0 = c    1∫dn = n + c   2∫eⁿdn = eⁿ + c
3∫aⁿdn = aⁿ / ln(a) + c   4∫dn / n = ln|n| + c
5∫cos(n)dn = sin(n) + c   6∫sin(n)dn = -cos(n) + c

7∫nⁱdn = (nⁱ⁺¹ | i + 1) + c,    где i ≠ -1, n > 0
8∫dn / sin²(n) = -ctg(n) + c    9∫dn / cos²(n) = tg(n) + c
        _______
a∫dn | √a² - n² = arcsin(n / a) + c, |n| < |a|
b∫dn | a² + n² = 1/a arctg(n / a) + c

c∫dn | a² - n² = 1/2a ln|(a + n) / (a - n)| + c - высокий, |n| ≠ a
